# Data provenance and disclaimers

This directory contains the scripts and raw snapshots used to create the
datasets bundled with `ggconsulting`. It is excluded from package builds by
`.Rbuildignore`, so the provenance recorded here is also summarized in the
dataset documentation in `R/data.R`.

## Important notes

- `bu_quarterly`, `client_nps`, `ebitda_bridge`, and `market_share` are
  synthetic datasets generated by the `ggconsulting` authors. They do not
  describe real companies, clients, survey respondents, financial results,
  or market shares. Names and values are illustrative and should not be
  treated as evidence or used for inference.
- `br_macro` and `ibov_sectors` are frozen, transformed snapshots rather
  than live data feeds. Historical values can be revised by the source
  organizations.
- The MIT license for this package does not replace or expand any terms that
  apply to external source data. Check the current terms of the source
  organizations before refreshing or redistributing these snapshots.
- `ggconsulting` is not affiliated with, sponsored by, or endorsed by the
  Banco Central do Brasil, IBGE, B3, `rbcb`, or `rb3`.

## Dataset provenance

### Synthetic datasets

| Dataset | Script | Provenance and disclaimer |
|:--|:--|:--|
| `bu_quarterly` | `bu_quarterly.R` | Synthetic quarterly P&L and headcount for a fictional conglomerate. |
| `client_nps` | `client_nps.R` | Synthetic quarterly NPS and response counts for fictional client segments. |
| `ebitda_bridge` | `ebitda_bridge.R` | Synthetic EBITDA bridge for the same fictional conglomerate. |
| `market_share` | `market_share.R` | Synthetic market shares for fictional players in a fictional sector. |

These scripts use fixed random seeds where randomness is needed so that the
examples can be regenerated reproducibly. No external data producer is
being represented by these datasets.

### `br_macro`

Source credit: Banco Central do Brasil (BCB), Sistema Gerenciador de Séries
Temporais (SGS), retrieved with the [`rbcb`](https://cran.r-project.org/package=rbcb)
R package. The source series are:

| Column | BCB SGS series | Definition |
|:--|--:|:--|
| `selic` | 4189 | Selic accumulated in the month, annualized, base 252 (% p.a.). |
| `ipca_12m` | 13522 | IPCA over the previous 12 months (%). |
| `ibc_br` | 24364 | IBC-Br, seasonally adjusted (index). |
| `usd_brl` | 3696 | USD/BRL, sale rate, end of period. |
| `unemployment` | 24369 | PNADC unemployment rate (%); source indicated by BCB as IBGE. |

The official BCB SGS portal is <https://www3.bcb.gov.br/sgspub/> and the
official API is documented through the corresponding series endpoints under
<https://api.bcb.gov.br/dados/serie/>. The snapshot is fetched for
2012-01-01 through 2024-12-31, then published as a rounded, filtered
2012-03 through 2024-12 table. The source data are monthly; this script does
not aggregate daily observations.

### `ibov_sectors`

Source credit: B3 S.A. – Brasil, Bolsa, Balcão, historical series for the
Ibovespa and B3 sector indices (`IBOV`, `IFNC`, `INDX`, `IMAT`, `IEEX`, `ICON`,
and `IMOB`), retrieved with the [`rb3`](https://github.com/ropensci/rb3)
R package. B3's historical-series page is
<https://www.b3.com.br/pt_br/market-data-e-indices/servicos-de-dados/market-data/historico/mercado-a-vista/series-historicas/>.

The raw snapshot includes 2019-12 as a baseline so that the first published
monthly return for 2020-01 can be computed. `close` is the end-of-month
observation selected from the daily series, and `return_m` is calculated by
this repository as the arithmetic change between consecutive monthly
observations. The snapshot ends on 2024-12-31 and is not a live or official
current index feed.
